        CASCADE DE IF ELSE 

switch(expression)
{
    case constante1 : instruction 1 ou bloc 1 d'instructions
                      break;
    case constante2 : instruction 2 ou bloc 2 d'instructions
                      break;
    case constante3 : instruction 3 ou bloc 3 d'instructions
                      break;
    default         : instruction 5 ou bloc 5 d'instructions
                      break;
}

Si la valeur de expression est constante1, l'instruction1 (ou le bloc1) s'exécute puis l'instruction break provque la sortie de la structure switch.
Si aucune constante ne correspond à la valeur de l'expression, c'est l'instruction 5 (ou le bloc 5, derrière default) qui est exécuté. La ligne default n'est pas obligatoire.

        TRANSTYPAGE

Méthode pour réaffecter un type à une variable qui en avait déjà un. Exemple :

int main()
{
    uint8_t a=5,b=22;
    float c;
    c=b/a;
    printf("division sans transtypage %4.2f\n",c);
    c=(float)b/a;
    printf("division sans transtypage %4.2f\n",c);}

le premier print renvoie 4.00 alors que le deuxieme renvoie 4.40. Dans le premier cas on converti en flotant après la division alors que dans le deuxieme cas on converti avant la division

        STRUCTURES 

Typedef signifie que l'on crée un nouveau type de variable. Exemple :

typedef struct {double latitude; double longitude; int16_t altitude;}CoordGPS;
int main()
{
    CoordGPS CoordonneesArcueil={48.8036,2.3317,61};
    printf("Coordonnées d'Arcueil %f %f %d\n",   CoordonneesArcueil.latitude,
                                                 CoordonneesArcueil.longitude,
                                                 CoordonneesArcueil.altitude);

    return 0;
}

 
Une structure peut contenir des tableaux, des chaînes de caractères et même des structures. Exemple

typedef struct {double latitude; double longitude; int16_t altitude;}CoordGPS;
typedef struct {char nom[30];CoordGPS coordonnees; int nb_habitants;}ville;
int main()
{

                                            Arcueil.coordonnees.latitude,
                                            Arcueil.coordonnees.longitude,
                                            Arcueil.coordonnees.altitude);
    return 0;
